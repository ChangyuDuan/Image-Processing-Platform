# AI视觉领域图片数据特征统计分析



## 2.1 底层通用特征

定义：图片的固有属性，不依赖具体视觉任务，是数据预处理的基础分析内容，所有视觉任务均需开展此类特征统计。具体分类及统计要求如下表：

| 特征子类       | 核心统计内容                                                 | 必选统计指标                                                 |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 颜色特征       | RGB、HSV等主流颜色空间各通道基础信息，颜色分布、主色调相关信息 | 各颜色通道的均值、方差、偏度、峰度、最值；颜色直方图；主色调占比；平均亮度、亮度动态范围、饱和度均值 |
| 纹理与边缘特征 | 图片纹理粗糙程度、边缘分布特征及细节丰富度（需特定算法算子计算） | 灰度共生矩阵（GLCM）四维度指标（对比度、相关性、能量、同质性）；边缘像素占比、边缘方向直方图（基于Canny/Sobel算子）；傅里叶频域成分分布（高频、低频占比） |
| 形状与空间特征 | 图片自身尺寸属性、目标轮廓特征及像素/目标的空间位置关系      | 图片高、宽及宽高比；目标轮廓的长宽比、面积、周长；目标中心坐标分布；像素空间自相关性（局部方差分布） |

定义：图片的固有属性，不依赖具体视觉任务，是数据预处理的基础分析内容，所有视觉任务均需开展此类特征统计。
